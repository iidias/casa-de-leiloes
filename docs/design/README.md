# Design

Protótipo de média fidelidade, usado só como referência visual. Não é o frontend da aplicação, que fica em `frontend/`.

- `PROTOTIPOS TELAS/`: prints das telas em desktop (`d-`) e celular (`m-`). As obras aparecem com uma imagem provisória.
- `CODIGO BASE GERADO POR FIGMA MAKE/`: o código que o Figma Make gerou. Ele não foi feito para compilar fora do Figma, e os dados são fictícios.

A direção visual está registrada na decisão D11, em `docs/DECISIONS.md`.
